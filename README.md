## 🏛️ CivicPulse — AI-Powered Citizen-to-Infrastructure Intelligence Platform

### 📌 Problem Statement
Governments receive large volumes of citizen development requests across different languages and regions, making it difficult to identify infrastructure gaps and prioritize development projects effectively.

### 📊 Dataset
The MVP uses synthetic data representing:
- Citizen development requests
- District and regional information
- Population and demographic indicators
- Infrastructure conditions
- Investment and development gaps

The dataset includes sample requests in **English, Hindi, and Bengali** across multiple Indian districts.

### 🧠 Approach
CivicPulse transforms citizen feedback into structured development intelligence through the following pipeline:

**Citizen Request → AI Understanding → Structured Development Need → Geographic Aggregation → Infrastructure & Demographic Analysis → Priority Scoring → Policy Recommendation**

The platform analyzes citizen requests, identifies development sectors and locations, aggregates regional demand, and generates transparent priority scores to identify high-impact infrastructure needs.

### 🔍 Key Insights
- Identifies regions with concentrated citizen demand.
- Detects infrastructure gaps and underserved areas.
- Combines citizen feedback with demographic and infrastructure indicators.
- Provides transparent, evidence-based priority scores for decision-making.

### 🛠️ Tech Stack
- React + Vite
- Node.js
- Express.js
- MongoDB + Mongoose
- AI/LLM Integration
- Leaflet / Map Visualization
- Recharts / Chart.js

### 📈 Results
Built a functional MVP that allows citizen requests to be submitted, analyzed, geographically aggregated, and converted into prioritized infrastructure insights through an interactive analytics dashboard.


🔗 **Repository:** [View Project](https://civicpulse-tawny-nine.vercel.app/)

## 🎥 StreamTube — Full-Stack Video Streaming Platform

### 📌 Problem Statement
Modern video platforms require an intuitive interface for discovering and consuming video content. StreamTube was built to explore the architecture and development of a full-stack video streaming platform inspired by modern video-sharing applications.

### 📊 Dataset
The application uses application-generated data stored and managed through **MongoDB**, including video-related information and user/application data.

### 🧠 Approach
The project follows a full-stack MERN architecture:

**Frontend User Interface → API Requests → Express.js Backend → MongoDB Database**

The frontend provides an interactive video browsing experience, while the backend manages application logic, APIs, and database operations.

### 🔍 Key Insights
- Demonstrates communication between a React frontend and Node.js backend.
- Implements RESTful APIs for managing application data.
- Uses MongoDB for flexible and scalable data storage.
- Explores real-world full-stack application architecture.

### 🛠️ Tech Stack
- MongoDB
- Express.js
- React.js
- Node.js
- JavaScript
- REST APIs

### 📈 Results
Successfully developed a working MERN-based video platform demonstrating frontend-backend integration, API development, database connectivity, and modern web application architecture.
